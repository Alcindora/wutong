What is this?

A working instrument-cluster renderer that runs entirely in the browser. Both gauges are drawn on <canvas> every animation frame — ticks, arcs, numerals and needles are computed in JavaScript, not images. It is a reference implementation for anyone building dashboard or HMI interfaces on the web.

Features

  • Spring-physics needles (stiffness + damping), no CSS transitions
  • Drive simulation with acceleration, cruise and regenerative braking
  • Eco / Comfort / Sport modes re-tune ranges, redline and accent color
  • Dark & light cluster themes, live clock, tell-tale indicators
  • Retina-aware canvas sizing, zero dependencies, zero build step

How it works

One requestAnimationFrame loop integrates a simple vehicle model (throttle → power → speed, with drag and regen), then feeds both values through independent spring integrators so the needles overshoot and settle like real stepper-motor gauges. Drawing code is plain Canvas 2D paths.

Reuse it

The whole demo is a single index.html in the GitHub repository (MIT). Copy the gauge renderer, change the scales, and it becomes a tachometer, a pressure gauge, or an industrial dashboard.
